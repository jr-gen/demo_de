IMPLEMENTATION

How this demo works

  1. Select a customer scenario.
  2. Confirm the purpose.
  3. Click Launch Messenger.
  4. The page writes the custom attributes first.
  5. Messenger opens only after that write succeeds.
  6. The published inbound message flow retrieves the attributes and routes the interaction.
Demo data only. Use synthetic values. Do not enter passwords, authentication codes, payment-card data, bank-account details, full Social Security numbers, security-question answers, or unrelated sensitive information.
