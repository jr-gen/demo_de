HOW IT WORKS

Simple handoff from the landing page to Genesys Cloud

1
Landing page

The calling application exposes the current customer and interaction context to this page through JavaScript or URL parameters.

2
Messenger

After a purpose is selected, the page passes the context to Messenger as custom participant data and opens the conversation.

3
Genesys Cloud

The published message flow receives the request, applies the configured business-hours logic, and connects the interaction to the support queue.

4
Specialist

The specialist receives the request with the supplied context in the interaction and can respond directly.

Demo data only. Use synthetic values. Do not enter passwords, authentication codes, payment-card data, bank-account details, full Social Security numbers, security-question answers, or unrelated sensitive information.
